홈개인정보처리방침이용안내

skin-crm

개발자가 자신의 Google Drive에 개발·테스트용 암호화 백업을 보관하고 복구하는 개인용 도구입니다. 현재 실제 고객을 대상으로 서비스하거나 실제 고객 정보를 보관하지 않습니다.

제공 기능

  • 가상 데이터 PostgreSQL DB의 암호화 백업
  • 사용자 Drive의 전용 백업 폴더에 암호화본과 체크섬 보관
  • 백업 다운로드·복호화·별도 DB 복원 확인

Google Drive 권한

현재 운영자가 승인한 전체 Drive 권한을 사용합니다. 권한 자체는 전체 Drive 파일 접근을 허용하지만, 현재 백업 작업은 전용 백업 경로의 암호화본과 체크섬을 전송·확인하도록 구성되어 있습니다. 계정 접근 권한과 실제 작업 범위는 구분됩니다.

복호화 키와 인증 토큰은 백업 파일과 함께 Drive에 업로드하지 않습니다.

개인정보처리방침에서 데이터 이용·보관·삭제와 권한 철회 방법을 확인할 수 있습니다.

현재 개발용 가상 데이터만 취급합니다.
